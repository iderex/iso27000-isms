# iso27000-isms

Working material on the ISO/IEC 27000 series and building an ISMS.

Note on copyright: the ISO standards are paid, copyrighted documents.
This repository does not reproduce any text from them. References are
by standard, clause number and edition only (for example
ISO/IEC 27001:2022, 6.1.3). Everything in this repository is original
material.

Planning and progress live in the issue tracker.
