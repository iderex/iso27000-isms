# iso27000-isms

The ISO/IEC 27000 family as it relates to an information security
management system, worked by the practices of scientific work.

## The first rule of this repository

ISO standards are copyrighted, paid documents. **This public repository
reproduces no normative text.** References are by standard, clause number
and edition (ISO/IEC 27001:2022, 6.1.3). Summaries are own words at the
level a summary may take. Artefacts here - policies, registers, mappings,
tooling - are original work implementing the requirements, never copies of
them. History cannot be unpublished, so this rule binds from the first
commit.

## Working practice

- The family catalog is derived from ISO's public catalog with the date of
  the read, never from memory.
- Every mapping cites both ends by clause and edition. Editions are pinned;
  an edition change is a tracked event.
- Artefacts are machine-readable where possible, so a mapping naming a
  control that does not exist in its declared edition can be refused.
- What was not read from a primary source is said to be worked from public
  summaries, never silently treated as read.

This repository begins with a planning phase. Nothing is built until the
plan has been reviewed by something that did not write it. The plan lives
in this tracker.
